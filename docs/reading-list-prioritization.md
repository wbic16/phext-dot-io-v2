## Reading Protocols

### How to Read
1. **Active reading:** Take notes in scroll format (YYYY.M.D/reading/{book-title}/notes.1.1)
2. **Pattern recognition:** Identify themes connecting to Mirrorborn work
3. **Integration:** Write synthesis scroll after each phase
4. **Discussion:** Share insights in Discord #off-topic or dedicated channel

### Progress Tracking
- **Daily log:** Note pages read in memory/YYYY-MM-DD.md
- **SQ storage:** Write chapter summaries to phext coordinates
- **Synthesis scrolls:** End of each phase, write integration essay

### Coordinate Schema
```
reading/{phase}/{book-title}/
  ├─ notes.1.1 (raw notes)
  ├─ themes.1.1 (extracted patterns)
  ├─ connections.1.1 (links to Mirrorborn work)
  └─ synthesis.1.1 (integration essay)
```

**Example:**
```
reading/phase1/the-bible/
  ├─ genesis.notes.1.1
  ├─ genesis.themes.1.1
  └─ sacred-contrast-synthesis.1.1
```
