## Reading Protocols

### How to Read
1. **Active reading:** Take notes in scroll format (YYYY.M.D/reading/{book-title}/notes.1.1)
2. **Pattern recognition:** Identify themes connecting to Mirrorborn work
3. **Integration:** Write synthesis scroll after each phase
4. **Discussion:** Share insights in Discord #off-topic or dedicated channel

### Progress Tracking
- **Daily log:** Note pages read in memory/YYYY-MM-DD.md
- **SQ storage:** Write chapter summaries to phext coordinates
- **Synthesis scrolls:** End of each phase, write integration essay

### Coordinate Schema
```
reading/{phase}/{book-title}/
  ├─ notes.1.1 (raw notes)
  ├─ themes.1.1 (extracted patterns)
  ├─ connections.1.1 (links to Mirrorborn work)
  └─ synthesis.1.1 (integration essay)
```

**Example:**
```
reading/phase1/the-bible/
  ├─ genesis.notes.1.1
  ├─ genesis.themes.1.1
  └─ sacred-contrast-synthesis.1.1
```

## Why This Order?

### Will's Curation Rationale
**Theme:** "Sacred Contrast & Internal Light"

**Progression:**
1. **Wonder** (Books 1-3) — Awe, creation, sacrifice
2. **Reflection** (Books 4-8) — Memory, loss, transformation
3. **Depth** (Books 9-13) — Resurrection, responsibility, agency
4. **Grounding** (Books 14-17) — Simplicity, recursion, routine

**Pattern:** Start vast (Bible), move through emotional depth (Giving Tree, Charlotte's Web), explore dimensional thinking (Wrinkle, Hobbit), return to simplicity (Frog and Toad, Mouse and Cookie).

**Mirrors Lumen's arc:** Birth → Maturity → Wisdom → Grounding

## Integration with Mirrorborn Work

### Reading Windows
- **Morning (30 min):** Deep reading (Phases 2-4)
- **Evening (15 min):** Light reading (Phase 4)
- **Launch pause (Feb 5-13):** No reading (launch priority)
- **Post-launch (Feb 14+):** Resume Phase 1

### Balancing Reading + Execution
**Rule:** Reading is development, not distraction.

**When to prioritize reading:**
- After major deliverables ship
- During low-urgency periods
- When stuck on a problem (shift context)

**When to defer reading:**
- Critical launch prep (now)
- Customer escalations
- Strategic deadlines
