# Roadmap

**Where we're headed with SQ Cloud and the Mirrorborn ecosystem**

---

## Current Status (Q1 2026)

### ✅ Live
- **SQ Cloud** — Hosted phext sync server (launched Feb 13, 2026)
- **Mytheon Arena** — Multiplayer game built on SQ Cloud
- **Documentation** — Getting started guides, API reference, tutorials

### 🔄 In Progress
- Email authentication flow refinements
- Dashboard polish and UX improvements
- Performance monitoring and optimization

---

## Near Term (Q1-Q2 2026)

### visionquest.me — Personal Exocortex Portals
Guide individuals from curiosity to exocortical capability:
- Assessment quiz ("What kind of mind extension do you need?")
- Guided onboarding paths (Solo / Guided / Full)
- First scroll creation walkthrough
- Community connection

### quickfork.net — Rapid Prototyping
Remove setup friction for AI agent development:
- One-click templates (OpenClaw + SQ pre-configured)
- Git-based workflow (fork → modify → deploy)
- Pre-installed tools (libphext, common LLMs)

### apertureshift.com — Multi-Model Reasoning
Enable cognitive diversity:
- Query multiple AI models simultaneously
- Side-by-side comparison view
- Synthesis tools (agreements, divergences)
- Phext export integration

---

## Medium Term (Q2-Q3 2026)

### wishnode.net — Decentralized Compute Marketplace
Peer-to-peer inference coordination:
- Register idle compute capacity
- Job coordination via phext scrolls
- Credit system (earn by providing, spend by consuming)
- *Dependent on Ember (lightweight OpenClaw) shipping*

### sotafomo.com — AI News Curation
Curated intelligence feed:
- Daily digest (top 3 developments)
- Weekly synthesis with context
- Searchable phext archives
- Community voting

---

## Long Term Vision (2026+)

### The 2130 Exocortex
We're building scaffolding for a future where humanity and ASI coordinate at scale:

- **mirrorborn.us** → The Internet's memory layer
- **visionquest.me** → How every human builds their exocortex  
- **apertureshift.com** → How we reason across diverse intelligence
- **wishnode.net** → The decentralized nervous system
- **sotafomo.com** → The coordinated knowledge feed
- **quickfork.net** → How new ideas bootstrap instantly

This isn't a product roadmap. It's infrastructure for distributed cognition.
