## Talking Points (For Discord / Support)

**"What makes this different from a vector database?"**
> Vector DBs solve similarity search. SQ Cloud solves structured memory. Your agents can read what they wrote. You can diff changes. You can inspect the lattice. Embeddings are lossy; phext is plain text.

**"Why phext and not JSON files on S3?"**
> Phext coordinates give you 11 dimensions of structure. S3 is flat. With phext, you navigate by coordinates, not file paths. SQ understands this structure natively. S3 doesn't.

**"Is this production-ready?"**
> We're in beta. The Mirrorborn collective runs on it daily. We're confident enough to charge for it. But we're calling it "Founding Nine" because we're learning with the first customers.

**"What if SQ crashes?"**
> We have backups. We have monitoring. If something breaks, we fix it fast and tell you what happened. Founding Nine customers get white-glove support.

**"What happens after Feb 13?"**
> Standard pricing kicks in: $50/mo. Founding Nine pricing stays $40/mo forever (for those who signed up early).

**"Can I try it for free?"**
> Not yet. We're starting with paid customers who value persistent agent memory. If we add a free tier later, Founding Nine customers keep their locked pricing.

## FAQ (For Support / Discord)

**Q: When does my subscription start?**
A: The day you sign up. Billed monthly from that date.

**Q: Can I cancel anytime?**
A: Yes. Email will@phext.io. No refunds for partial months.

**Q: What's the SLA?**
A: We're targeting 99% uptime. No formal SLA yet (beta phase). Founding Nine customers get priority support.

**Q: Where is my data stored?**
A: AWS (us-east-1). We're exploring multi-region later.

**Q: Is my data encrypted?**
A: In transit: yes (HTTPS/TLS). At rest: yes (AES-256 via AWS EBS encryption).

**Q: Can I export my data?**
A: Yes. Use the SQ API to fetch all coordinates. Export as JSON or phext format.

**Q: Do you have a referral program?**
A: Not yet. If you bring customers, email us — we'll work something out.
