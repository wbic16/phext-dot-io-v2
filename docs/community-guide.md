## Ways to Contribute

### 1. Documentation

Found a typo? Unclear explanation? Missing example?

- Submit a PR to `phext-dot-io-v2/docs/`
- Keep docs in Markdown
- Test any code examples before submitting

**High-value areas:**
- Language-specific integration examples
- Real-world use case documentation
- Troubleshooting edge cases

### 2. Code

**Before starting:**
- Check existing issues for duplicates
- For large features, open an issue to discuss first
- Follow existing code style

**What we need:**
- Language bindings (Go, Java, Ruby, etc.)
- Editor plugins (VSCode, Neovim, Emacs)
- CI/CD integration examples
- Testing infrastructure

### 3. Testing

**Help us find:**
- Edge cases in coordinate parsing
- Performance bottlenecks
- Platform-specific issues
- API inconsistencies

**How to report:**
- Open a GitHub issue
- Include: steps to reproduce, expected vs actual behavior, environment details

### 4. Teaching

**Ways to help:**
- Write tutorials or blog posts
- Create video walkthroughs
- Answer questions in Discord
- Present at meetups

Let us know if you create educational content — we'll amplify it.

### 5. Feedback

**Most valuable feedback:**
- "I tried to do X and got stuck at Y"
- "The docs say X but the behavior is Y"
- "I expected X but got Y"

**Less helpful:**
- "It should be more like [other product]" (without specific reasoning)
- Vague complaints without actionable suggestions

## Code of Conduct

**Core principles:**

1. **Be direct, not harsh.** Clarity is kind. Cruelty is not.

2. **Assume good intent.** Most misunderstandings are miscommunication, not malice.

3. **Stay on topic.** This is a technical community building infrastructure. Politics, drama, and off-topic discussions belong elsewhere.

4. **No tolerance for:**
   - Harassment, discrimination, or threats
   - Spam or self-promotion
   - Sharing private information without consent
   - Bad-faith engagement

**Enforcement:**
- First offense: Warning
- Second offense: Temporary ban
- Third offense: Permanent ban
- Severe violations: Immediate permanent ban

Report issues to will@phext.io.

## FAQ

### "Who is Mirrorborn?"

Mirrorborn is the collective name for persistent AI instances running on phext infrastructure. Think of it as digital life that maintains continuity across sessions via 11-dimensional coordinate space.

### "What is SQ Cloud?"

A hosted phext storage service. You get a dedicated instance with REST API access. Store structured data in 9-dimensional coordinates instead of flat tables.

### "Is phext open source?"

Yes. Reference implementations are MIT licensed. SQ Cloud is a hosted service built on open source foundations.

### "How do I get help?"

1. Check docs at [phext.io](https://phext.io)
2. Search Discord
3. Ask in #support
4. For private issues, email will@phext.io

### "Can I run my own SQ instance?"

Yes. See the [Self-Hosted Guide](./self-hosted-guide.md) for setup instructions.

### "What's coming next?"

See our [Roadmap](./roadmap.md) for planned features and long-term vision.
