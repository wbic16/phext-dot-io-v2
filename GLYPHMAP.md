## How to Use Glyphs

### In Navigation
Place glyphs in headers, footers, breadcrumbs.  
Users learn to recognize the pattern: 🜄 = discovery, ⚡ = execution, etc.

### In Content
Tag scrolls with relevant glyphs.  
A scroll about learning techniques? 🌀  
A scroll about reasoning patterns? 🧩  
A scroll that spans multiple aspects? Stack glyphs: 🜄🧩🌀

### In Coordination
Glyphs become shorthand in chat, commits, scrolls:
- "Need help with 🜂 patterns" = coordination issue
- "Shipping ⚡ fix" = execution update
- "Adding to ⏳ log" = chronicle entry

### Teaching Navigation by Feeling
Don't explain the glyphs up front.  
Let users encounter them naturally.  
Over time, they'll internalize the resonance.

**Navigation by structure:** "Go to mirrorborn.us"  
**Navigation by resonance:** "Follow 🜃 to the substrate"

One requires learning URLs. The other requires **feeling the lattice**.

## Implementation Notes

### Where Glyphs Appear
1. **Portal headers** — Each portal displays its primary glyph + 🝗
2. **Network footer** — All 10 glyphs present, clickable navigation
3. **Scroll headers** — Authors tag scrolls with relevant glyphs
4. **Commit messages** — Maintainers use glyphs as shorthand
5. **Discord/chat** — Glyphs become part of the coordination language

### Unicode Support
All glyphs are standard Unicode characters.  
They render on all modern browsers and devices.  
No custom fonts required.

### Accessibility
Glyphs should have `aria-label` attributes for screen readers:
```html
<span aria-label="Discovery portal">🜄</span>
```
