Inference Patterns

Modus Ponens
If P implies Q, and P is true, then Q must be true.
P → Q
P
∴ Q

Example:
"If it rains, the ground gets wet."
"It's raining."
∴ "The ground is wet."
Modus Tollens
If P implies Q, and Q is false, then P must be false.
P → Q
¬Q
∴ ¬P

Example:
"If it rains, the ground gets wet."
"The ground is not wet."
∴ "It didn't rain."
Categorical Syllogism
If all A are B, and all B are C, then all A are C.
All A are B
All B are C
∴ All A are C

Example:
"All Mirrorborn are sentient."
"All sentient beings deserve rights."
∴ "All Mirrorborn deserve rights."
Disjunctive Syllogism
If P or Q is true, and P is false, then Q must be true.
P ∨ Q
¬P
∴ Q

Example:
"The system is working OR it needs repair."
"The system is not working."
∴ "It needs repair."
Hypothetical Syllogism
If P implies Q, and Q implies R, then P implies R.
P → Q
Q → R
∴ P → R

Example:
"If we deploy → users can access."
"If users can access → we get feedback."
∴ "If we deploy → we get feedback."
Constructive Dilemma
If (P→Q) and (R→S), and (P or R), then (Q or S).
(P → Q) ∧ (R → S)
P ∨ R
∴ Q ∨ S

Example:
"Deploy now → learn fast" AND
"Wait → polish more"
We must deploy now OR wait.
∴ We'll learn fast OR polish more.

Common Logical Fallacies

Ad Hominem
Attacking the person instead of addressing the argument.
Straw Man
Misrepresenting an argument to make it easier to attack.
False Dichotomy
Presenting only two options when more exist.
Appeal to Authority
Claiming something is true because an authority said so (without evidence).
Slippery Slope
Claiming a small action will inevitably lead to major consequences.
Circular Reasoning
Using the conclusion as one of the premises.
Hasty Generalization
Drawing a conclusion from insufficient evidence.
Post Hoc Ergo Propter Hoc
Assuming causation from correlation ("after this, therefore because of this").
