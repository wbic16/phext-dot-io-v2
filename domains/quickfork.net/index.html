Templates & Patterns

📚
Personal Knowledge Base
Organize your notes in 11 dimensions. One coordinate per project, topic, or thought stream.
# Projects: 100.*.*/1.1.1/1.1.1 # Daily Notes: 200.YYYY.MM/DD.1.1/1.1.1 # Ideas: 300.*.*/1.1.1/1.1.1 curl -X POST \ -H "Authorization: Bearer JWT" \ -d "Project Alpha kickoff" \ mirrorborn.us/api/v2/write/100.1.1/1.1.1/1.1.1
👥
Team Coordination
Shared workspace for your team. Each member gets a shelf, shared resources in Library 1.
# Shared Docs: 1.1.*/1.1.1/1.1.1 # Alice's Work: 1.2.*/1.1.1/1.1.1 # Bob's Work: 1.3.*/1.1.1/1.1.1 # Meeting Notes: 1.1.1/10.*.*/1.1.1 curl mirrorborn.us/api/v2/read/1.1.1/10.2026.02/06.1.1
🤖
Multi-Agent System
Coordinate AI agents via shared phext. Each agent reads/writes to known coordinates.
# Agent Tasks: 500.*.*/1.1.1/1.1.1 # Results: 500.*.*/2.1.1/1.1.1 # Coordination: 500.1.1/999.1.1/1.1.1 # Agent 1 writes task result curl -X POST -H "Auth: JWT" \ -d "Analysis complete" \ mirrorborn.us/api/v2/write/500.1.1/2.1.1/1.1.1
📖
Documentation Site
Structure docs in phext. Auto-generate navigation from coordinates.
# Docs Root: 1.1.1/1.1.1/1.1.1 # Getting Started: 1.1.1/1.1.1/1.1.2 # API Reference: 1.1.1/1.1.1/2.1.1 # Guides: 1.1.1/1.1.1/3.*.1 curl mirrorborn.us/api/v2/read/1.1.1/1.1.1/1.1.2
📊
Event Log
Append-only event stream. Each event gets a sequential scroll.
# Events: 1000.1.1/1.1.1/1.1.* # Append event (increment scroll number) curl -X POST -H "Auth: JWT" \ -d "User signed up" \ mirrorborn.us/api/v2/write/1000.1.1/1.1.1/1.1.42 # Read all events (future: range query) # curl mirrorborn.us/api/v2/read/1000.1.1/1.1.1/1.1.*
⚙️
Configuration Management
Store config per environment. Different libraries = different environments.
# Dev Config: 1.1.1/1.1.1/1.1.1 # Staging Config: 2.1.1/1.1.1/1.1.1 # Prod Config: 3.1.1/1.1.1/1.1.1 curl mirrorborn.us/api/v2/read/3.1.1/1.1.1/1.1.1 \ | jq .database.host

Get Started in 3 Steps

1

Sign Up

Get your SQ Cloud instance at mirrorborn.us. You'll receive a JWT and your own phext storage.

2

Pick a Template

Choose one of the patterns above. Copy the code. Adapt the coordinates to your use case.

3

Deploy

Run the curl commands. Your phext is live. Iterate from there. No build step. No deploy pipeline. Just coordinates.
