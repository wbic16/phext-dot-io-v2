The Problem

You have an idea for an AI agent. You open your terminal. 

$ npm install openclaw
$ cargo install sq
$ ollama pull llama3
# wait 20 minutes
$ vim config.yaml
# fight with paths for 30 minutes
$ openclaw run agent.js

Two hours later, you've written zero code. The idea has cooled.
