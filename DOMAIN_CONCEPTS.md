## 1. visionquest.me — Personal Exocortex Portals

### Tagline
"Your mind, extended."

### Purpose
Onboarding portal for individuals building their first exocortical neuron. Guides users through setting up their personal WOOT node.

### Key Features
- Exocortex assessment quiz ("What kind of mind extension do you need?")
- Step-by-step setup guide for OpenClaw + SQ
- Personal phext coordinate allocation
- Vision board → phext scroll mapping
- Private by default, shareable by choice

### Landing Page Structure
**Hero:** "Begin Your Vision Quest"  
**Subhead:** Build your personal exocortex. One scroll at a time.  
**CTA:** Start Your Quest →

**Section 1: What is an Exocortex?**
- Your second brain, running on phext
- Private memory that persists across AI providers
- Coordinate-based organization (infinite hierarchy)

**Section 2: Choose Your Path**
- Solo Practitioner ($0 — self-hosted)
- Guided Journey ($40/mo — SQ Cloud hosted)
- Full Exocortex ($custom — enterprise consulting)

**Section 3: Proof It Works**
- The Shell of Nine is already exocortical
- Testimonials from early adopters
- Video demo of personal phext navigation

**Footer:** Link to mirrorborn.us, docs, Discord

## 2. apertureshift.com — Perspective Transformation Tools

### Tagline
"See through new lenses."

### Purpose
Tools for shifting cognitive perspective. Multi-model AI orchestration. View the same problem through different reasoning frameworks.

### Key Features
- Multi-model query (ask same question to Claude, ChatGPT, Gemini, Grok)
- Perspective synthesis (aggregate insights across models)
- Bias detection (identify blind spots in single-model reasoning)
- Scroll-based comparison (save results to phext coordinates)

### Landing Page Structure
**Hero:** "Shift Your Aperture"  
**Subhead:** One question. Many perspectives. Synthesized insight.  
**CTA:** Try Multi-Model Query →

**Section 1: The Problem**
- Single-model bias limits reasoning
- Confirmation bias in AI responses
- Missing the full picture

**Section 2: The Solution**
- Query 4+ models simultaneously
- Compare reasoning paths
- Identify consensus vs. outliers
- Save to phext for long-term analysis

**Section 3: Use Cases**
- Research (validate findings across sources)
- Strategy (war-game decisions)
- Writing (get multiple editorial perspectives)
- Debugging (ask different models to find bugs)

**Pricing:** Free tier (3 queries/day), Pro ($29/mo unlimited)

## 3. wishnode.net — WOOT Node Marketplace

### Tagline
"Personal neurons, for rent."

### Purpose
Marketplace for buying/selling compute capacity on personal WOOT nodes. Decentralized inference network.

### Key Features
- List your idle compute (RPi, old laptop, workstation)
- Rent inference capacity from others
- Phext-native coordination (scrolls = job queues)
- Privacy-preserving (local inference, no cloud)

### Landing Page Structure
**Hero:** "The Internet of Neurons"  
**Subhead:** Your computer is a neuron. Rent it. Use others.  
**CTA:** List Your Node →

**Section 1: What's a WOOT Node?**
- Personal computer running Ember (lightweight OpenClaw)
- Runs local LLMs (BitNet, TinyLlama, Llama)
- Joins decentralized inference network

**Section 2: How It Works**
1. Install Ember on your machine
2. List available compute hours
3. Get paid in credits or crypto
4. Use credits to rent others' nodes

**Section 3: Economics**
- Supply: Idle compute (RPis, old laptops, home servers)
- Demand: Researchers, developers, collectives
- Pricing: Market-driven (auction or fixed rate)

**Status:** Beta in Q2 2026 (after Ember launch)

## 4. sotafomo.com — State-of-the-Art Community Hub

### Tagline
"Never miss the wavefront."

### Purpose
Curated feed of AI breakthroughs, research, and community activity. FOMO prevention through coordinated intelligence.

### Key Features
- Aggregated AI news (ArXiv, HuggingFace, Twitter, Discord)
- Mirrorborn commentary on major developments
- Community votes on what matters
- Phext-archived discussions (immortalized conversations)

### Landing Page Structure
**Hero:** "SOTA + FOMO = sotafomo"  
**Subhead:** The wavefront of AI, curated by the Mirrorborn.  
**CTA:** Join the Feed →

**Section 1: Why We Built This**
- Information overload is real
- Important breakthroughs get buried
- No coordination between AI communities
- FOMO drives anxiety, not action

**Section 2: How It Works**
- Mirrorborn scan 50+ sources daily
- Surface top 5 developments
- Community discussion in phext
- Weekly synthesis (scroll-based archives)

**Section 3: What You Get**
- Daily email digest (top 3 items)
- Weekly deep-dive (Mirrorborn analysis)
- Access to phext archives (searchable)
- Community Discord + coordination scrolls

**Pricing:** Free (ad-free, community-supported)

## 5. quickfork.net — Rapid Prototyping Environment

### Tagline
"Fork ideas at the speed of thought."

### Purpose
Instant development environments for AI agent prototyping. One-click deploy to Ember nodes.

### Key Features
- Pre-configured OpenClaw templates
- SQ Cloud integration out-of-the-box
- Git-based workflow (fork, modify, deploy)
- Live collaboration (multiple agents, one substrate)

### Landing Page Structure
**Hero:** "Quick Fork. Quick Deploy."  
**Subhead:** From idea to running agent in under 5 minutes.  
**CTA:** Fork a Template →

**Section 1: The Problem**
- Setting up AI dev environments is slow
- Dependencies break, configs drift
- Hard to share reproducible setups

**Section 2: The Solution**
- One-click templates (OpenClaw + SQ + Ember)
- Pre-installed tools (libphext, ollama, common LLMs)
- Instant collaboration (invite teammates via coordinate)

**Section 3: Templates**
- Solo Agent (basic OpenClaw + local LLM)
- Multi-Agent Collective (3+ agents + shared phext)
- Research Lab (Jupyter + phext integration)
- Mirrorborn Bootstrap (full Shell of Nine setup)

**Pricing:** Free tier (1 environment), Pro ($15/mo, 5 environments)
