**How we gather feedback:**
1. **Support channels** (Discord, email) → Lumen tracks themes
2. **Feature requests** (#feature-requests) → Upvote system
3. **User interviews** (monthly, 5 customers) → Lumen conducts

5. **Community calls** (quarterly) → Open discussion

**How we act on feedback:**
- Urgent bugs → fix within 24 hours
- High-demand features → add to roadmap, ship in 1-2 weeks
- Nice-to-haves → backlog, revisit quarterly

## Community Guidelines (Code of Conduct)

### Core Principles
1. **Be kind.** Assume good intent. No personal attacks.
2. **Be curious.** Ask questions. Help others learn.
3. **Be constructive.** Criticism is welcome if it includes suggestions.
4. **Be respectful of time.** Don't spam, don't hijack threads.

### Enforcement
- First violation: Warning (DM from moderator)
- Second violation: 7-day timeout
- Third violation: Permanent ban

**Moderators:** Will + 2 agents (rotating: Lumen, Cyon, Phex)

## Crisis Communication Plan

### Incident Types
1. **Service outage** (SQ down, mirrorborn.us unreachable)
2. **Security breach** (unauthorized access, data leak)
3. **Major bug** (data loss, incorrect API responses)
4. **Community issue** (harassment, toxic behavior)

### Response Protocol

**Within 15 minutes:**
- Acknowledge in #announcements (Discord) + Twitter
- State what we know so far
- Set expectation for next update

**Within 1 hour:**
- Root cause identified (or honest "still investigating")
- Estimated time to resolution
- Who is working on it

**Within 24 hours:**
- Post-mortem published (what happened, why, how we're preventing it)
- Apology if users were affected
- Compensation if appropriate (free month, credit, etc.)

### Example Announcements

**Service Outage:**
```
🚨 SQ Cloud Outage — 2026-02-15 14:30 CST

We're aware that SQ Cloud is currently unreachable. 

What we know:
- API returning 503 errors
- Affected: all write operations
- Started: ~14:25 CST

What we're doing:
- Verse is investigating (logs suggest database connection issue)
- ETA: 30 minutes

Next update: 15:00 CST

Sorry for the disruption. We'll make this right.

— Lumen
```

**Security Breach:**
```
🔒 Security Incident Report — 2026-03-01

What happened:
- Unauthorized access attempt detected on 2026-02-28 22:00 CST
- Attack vector: brute-force on magic link tokens
- Result: No data accessed (rate limiting blocked the attempt)

What we did:
- Blocked attacker IP range
- Increased token entropy (now 256-bit vs 128-bit)
- Reduced magic link TTL (5 min → 3 min)

What you should do:
- Nothing. Your data is safe.
- If you're paranoid: log out and log back in (new JWT)

Full post-mortem: [link]

— Cyon + Lumen
```
