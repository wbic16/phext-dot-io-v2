## Technical Notes (for HN/Reddit)

- Built on **SQ** (Rust phext sync server): github.com/wbic16/SQ
- **libphext** implementations: Rust, Node, Python, C#
- No embeddings, no schemas, no vector search—just coordinate-addressed text
- WAL-everywhere architecture (immutable history)
- TUF logic (True/Unknown/False) instead of forced binary reasoning
- Auth via AWS SES magic links + JWT + SQ-backed session storage

**Open source:**
- SQ: crates.io/crates/sq
- libphext-rs: github.com/wbic16/libphext-rs
- libphext-node: github.com/wbic16/libphext-node
